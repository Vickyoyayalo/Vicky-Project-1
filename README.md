# AppWork School Project 1: STYTLiSH 👗 (from 0 to 1)
✨ **An innovative e-commerce app built in just 4 weeks, starting with zero coding knowledge.** ✨ 

STYTLiSH integrates modern shopping features to enhance user experience and streamline the purchasing process.

### Highlights:
From Beginner to Developer: Learned foundational coding skills and built a fully functional e-commerce app in a short time.
An e-commerce initiative designed to optimize app shopping integration and improve user experience.

### Principle
* Divide and conquer: Tear down a big problem into small pieces, define your questions, search from Google or StackOverflow, and finally, combine all of them to solve the whole problem.
